# Community profiles

Profiles for regions whose hub isn't open yet. Each file is `<github-username>.json` and must pass [`../schema.json`](../schema.json).

The easiest way to add one is the form at https://jsrothwell.github.io/job-circles/join.html. It fills in the file for you and opens a pull request.

When a pull request is merged, the **Build community feed** workflow merges every file here into `../community.json`, which the site reads. When a region's hub launches, maintainers move that region's profiles to it.
