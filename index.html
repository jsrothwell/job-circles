Connecting senior global tech talent directly with recruiters — bypassing ATS filters and regional bias.

Experienced engineers outside the US are filtered out by keyword scanners, location checks and age proxies before a person ever reads their CV. The Rest of US is a public, federated directory: candidates publish structured profiles to regional hubs on GitHub, peers vouch for them in the open, and recruiters search everything here — with no middleman, no login and no fees.

For recruiters and hiring managers

No accounts, no paywall, no intermediary. Every profile is public data that its owner chose to publish.

Contact candidates directly

Every card has a Contact button that goes straight to the candidate by email, booking link or LinkedIn — whichever they prefer. Nothing is routed through us.

Export profile data

Download a single profile as JSON, or export your filtered shortlist as JSON or CSV for your own tracker. Or skip this UI and read the raw hub feeds listed below.

How peer vouches work

A vouch is added by the person giving it, in a pull request from their own GitHub account. Hub maintainers check that the PR author matches the voucher before merging, so every vouch has a public, traceable author. Where present, Verify links to that PR.

Regional hubs & raw feeds

Each hub is an independent GitHub repository run by its own maintainers. Hubs are listed in hubs.json; profiles follow profiles/schema.json.
